## How to update this file (every agent and human)

1. Tick an item (`- [x]`) only when its spec is **merged** with green CI — not when code is written.
2. Recalculate the phase line and summary row: % = ticked ÷ total, rounded down.
3. Status: ⬜ → 🟡 when the first spec starts; ✅ only when every item is ticked **and** the
   phase exit gate in `docs/ROADMAP.md` passes. Blocked → ⛔ and add the reason under the phase.
4. Update "Last updated", "Current phase", the overall bar, and add one line to the log.
5. Never delete items. If scope changes, add or strike through (`~~item~~ — reason`) and note it in the log.
6. Items here must match the **Build** line of the same phase in `docs/ROADMAP.md`.

From Phase 03, `yarn progress` recalculates the numbers and CI fails if this file is out of date.
